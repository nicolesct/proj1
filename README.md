This project presents a data-driven analysis of accommodation halls available at the London School of Economics and Political Science (LSE), focusing on key factors such as price, commute time to LSE, facilities, and type of rooms available. The aim is to provide insights into how different halls compare and what drives accommodation choices.

Methodology
Data collection – compiling information on LSE halls
Data cleaning – handling missing or inconsistent values
Exploratory data analysis (EDA) – identifying trends and distributions
Visualisation – using plots to highlight key insights
Interpretation – drawing conclusions from the results

This project was completed as part of an academic assignment at the London School of Economics, applying statistical and data analysis techniques to a real-world student decision problem.
